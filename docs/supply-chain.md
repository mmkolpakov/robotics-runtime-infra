# Supply-Chain Declaration

## SLSA Build Status

Standard release images built by GitHub-hosted runners target **SLSA Build
Level 2**. The workflow is hosted, source and dependencies are versioned, and
BuildKit provenance plus GitHub artifact attestations are published with each
image.

Level 3 is not claimed. The current workflow has not been separated into a
dedicated reusable build platform with the isolation and hardening evidence
required for that claim. Self-hosted hardware qualification consumes an
already attested image and does not rebuild it.

| Requirement | Hosted release image | Hardware qualification |
| --- | --- | --- |
| Version-controlled build definition | Yes | Yes |
| Hosted build service | GitHub-hosted Actions | Protected self-hosted runner |
| Provenance generated by build service | BuildKit and GitHub attestation | Consumes and verifies provenance |
| OCI subject pinned by digest | Yes | Required input |
| SBOM | SPDX attestation | Reuses release SBOM |
| Source revision binding | Git SHA | Verifies SHA and ancestry |
| Claimed SLSA Build level | L2 | No independent build-level claim |

The level is reassessed per release against the current
[SLSA specification](https://slsa.dev/spec/).

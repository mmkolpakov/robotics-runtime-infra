# Rclone binary update

CI run `34196040297` reported ten HIGH/CRITICAL findings in the ARM64
evidence-sink's rclone 1.75.0 binary, involving Go stdlib, `golang.org/x/crypto`
and `golang.org/x/image`. These findings are outside the linux-libc-dev VEX scope.

[Upstream 1.75.1 release notes](https://rclone.org/changelog/#v1-75-1-2026-09-04)
describe the corresponding dependency security fixes. The Dockerfile now pins
the actual 1.75.1 registry index. Inspection of its amd64 and arm64 binaries found
Go 1.27.1, x/crypto 0.56.0 and x/image 0.45.0 in both. Registry descriptor and layer
hashes were verified before inspecting ELF build metadata; neither binary has an
ELF interpreter dependency.

Retained binary SHA-256:

- amd64: `d059291c046edc38189135e42e7bc7d92112bfd9407554949f7d827993ee59a6`
- arm64: `e1bef296f517f10845630d080060b9712e0a82c67590cc344ad45e2106616293`

This is an upstream binary update, with no new scanner exception. A new image
build, Trivy scan and evidence transfer integration are required to qualify the
resulting images. Binary metadata alone does not establish those results.
